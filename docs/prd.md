# PRD: 모카당당 랜딩페이지 (실습용 가상 업체)

## 목표 (방문자의 행동 하나)
- 방문자가 '구독 시작하기' 버튼을 누른다. (요청서: "이것 하나만")
- 알리는 내용: 원두 정기구독 서비스 '모카당당' — 매달 다른 산지의 스페셜티 원두를 로스팅 당일 발송한다.
- 성공 기준 숫자(전환율 등)는 요청에 없으므로 정하지 않는다.

## 대상 고객
- 20~30대 직장인과 홈카페족
- 참고 사이트: 없음. 요청서의 섹션 구성을 그대로 따른다.

## 페이지 구조
한 페이지로 스크롤하는 원페이지. 순서는 요청서 그대로이며 바꾸지 않는다. 모든 화면은 모바일 가로 390px에서 깨지지 않아야 한다(필수).

| 순서 | 섹션 | id (제안) | 비고 |
|---|---|---|---|
| 1 | 상단 메뉴 | `top` (header) | 로고 글자 + 메뉴 5개 |
| 2 | 첫 화면 | `hero` | 구독 시작하기 버튼 |
| 3 | 브랜드 이야기 | `brand` | 메뉴 '브랜드' 이동 대상 |
| 4 | 대표 상품 | `products` | 카드 3개, 첫 카드 가장 눈에 띄게 |
| 5 | 이번달 원두 | `bean` | 어두운 초록 띠 |
| 6 | 고객 후기 | `reviews` | 카드 3개 + 하단 작은 글씨 |
| 7 | 마무리 띠 | `subscribe` | 어두운 초록 띠, 메뉴 '구독하기' 이동 대상 |
| 8 | 꼬리말 | `footer` | |

메뉴 연결(제안): 브랜드 → `#brand` / 상품 → `#products` / 이번달 원두 → `#bean` / 후기 → `#reviews` / 구독하기 → `#subscribe`

## 기능 (버튼 · 양식 · 링크 동작)
- 상단 메뉴: 누르면 해당 섹션으로 부드럽게 이동(앵커). 로고 '모카당당'은 글자만 있으며 링크 여부는 요청에 없음(제안: 맨 위로 이동).
- 모바일(390px) 메뉴 표시 방식(메뉴 5개가 가로로 안 들어갈 경우)은 디자이너/빌더가 정한다. 단, 메뉴 5개가 모두 접근 가능해야 한다.
- '구독 시작하기' 버튼(첫 화면, 마무리 띠): 요청서에 이동할 주소·결제·가입 양식이 없다. [확인 필요] 임시 동작(제안): 마무리 띠의 `#subscribe`로 이동하거나 연결 주소가 정해질 때까지 자리 표시 링크로 둔다.
- 양식(입력창): 요청에 없음. 만들지 않는다.
- 상품 카드 '구독하기'(원두 정기구독), '담기'(싱글오리진, 드립백): 요청서에 있는 버튼이지만 방문자 행동 하나('구독 시작하기')라는 목표와 충돌할 수 있다. [확인 필요] 처리 방법은 열린 질문 참조. 확정 전에는 문구를 그대로 두되, 장바구니·결제 기능은 만들지 않고 자리 표시 링크로 둔다.
- 후기 카드: 별점·좋아요 등 기능 없음.

## 섹션별 문구
사용자가 준 문구는 그대로이며, '제안'으로 표시한 것만 새로 쓴 것이다.

### 1. 상단 메뉴
- 로고 글자: 모카당당
- 메뉴: 브랜드 · 상품 · 이번달 원두 · 후기 · 구독하기

### 2. 첫 화면 (`hero`)
- 작은 제목: Coffee Subscription
- 큰 제목: 모카당당
- 부제: 매달, 새로운 한 잔의 발견
- 설명: 매달 다른 산지의 스페셜티 원두를, 로스팅 당일 바로 보내드려요. 20~30대 직장인과 홈카페족을 위한 원두 정기구독.
- 버튼: 구독 시작하기

### 3. 브랜드 이야기 (`brand`)
- 작은 제목: Our Story
- 제목: 한 달에 한 번, 새로운 산지의 발견
- 설명: 모카당당은 매달 다른 산지의 스페셜티 원두를 골라 로스팅 당일 발송하는 정기구독 서비스입니다. 매번 같은 원두가 아니라, 매번 다른 이야기와 풍미를 한 잔에 담아 보내드려요.

### 4. 대표 상품 (`products`) — 카드 3개
섹션 제목은 요청에 없음. 제안: 섹션 제목 없이 두거나 '대표 상품'(제안, 메뉴 이름 '상품'과 맞춤)으로 표시.

카드 1 (대표 상품, 가장 눈에 띄게)
- 이름: 원두 정기구독
- 설명: 월 1회 · 200g · 매달 다른 산지
- 안내: 첫 달 배송비 무료
- 가격: 15,900원/월
- 버튼: 구독하기

카드 2
- 이름: 싱글오리진 원두 200g · 에티오피아 예가체프
- 안내: 로스팅 당일 발송
- 가격: 12,000원
- 버튼: 담기

카드 3
- 이름: 드립백 10입 세트
- 설명: 사무실용 · 개별 포장
- 안내: 한 봉씩 바로 내려 마시기 좋아요
- 가격: 14,000원
- 버튼: 담기

### 5. 이번달 원두 (`bean`) — 어두운 초록 배경 띠
- 작은 제목: This Month's Bean
- 제목: 9월의 원두: 에티오피아 예가체프
- 설명: 시트러스, 자스민, 복숭아가 겹치는 밝은 산미와 은은한 꽃향. 고지대 워시드 공정으로 가공한 원두를 로스팅 당일 바로 발송합니다.
- ('9월' 표기는 요청 그대로 유지. 오늘 날짜와 맞는지는 확인 필요 목록 참조)

### 6. 고객 후기 (`reviews`) — 카드 3개 (실습용 가상 후기)
섹션 제목은 요청에 없음. 제안: '고객 후기'.
- "매달 다른 산지 원두가 온다는 게 이렇게 재밌을 줄 몰랐어요. 이번 달 우일라는 인생 원두였습니다." — 직장인 이OO님
- "로스팅 당일 발송이라 도착했을 때 향이 정말 진해요. 홈카페 시작하고 제일 잘한 선택." — 홈카페족 박OO님
- "드립백 세트는 사무실에 두고 동료들이랑 나눠 마시기 딱이에요. 개별 포장이라 위생적이고요." — 사무실 구독자 최OO님
- 섹션 아래 작은 글씨(필수): ※ 실습용 예시 후기입니다
- 별점, 후기 개수, 평균 점수는 넣지 않는다.

### 7. 마무리 띠 (`subscribe`) — 어두운 초록 배경
- 제목: 매달, 새로운 한 잔을 발견하세요
- 설명: 첫 달 배송비 무료로 지금 시작해보세요.
- 버튼: 구독 시작하기

### 8. 꼬리말 (`footer`)
- © 2026 모카당당. All rights reserved.
- 연락처, 사업자 정보, 약관, SNS 링크는 요청에 없으므로 넣지 않는다.

## 이미지 배치 (파일명 → 섹션)
현재 실제 이미지 파일은 없다. 모든 이미지는 '이미지 자리'(빈 틀 + 대체 설명)로 처리하고, 아래 파일명은 나중에 교체할 때 쓰도록 기록한다. 요청서는 "5장 첨부"라고 했지만 파일명은 4개만 나와 있다.

| 파일명 | 들어갈 섹션 | 비고 |
|---|---|---|
| 01_이번달원두_포스터 | 5. 이번달 원두 (`bean`) | |
| 02_원두정기구독_데일리브루 | 2. 첫 화면 (`hero`) + 4. 상품 카드 1 | 같은 파일을 두 곳에 사용 |
| 03 (파일 전체 이름 [확인 필요]) | 4. 상품 카드 2 (싱글오리진) | 요청서에 "이미지 03"만 적힘 |
| 04 (파일 전체 이름 [확인 필요]) | 4. 상품 카드 3 (드립백) | 요청서에 "이미지 04"만 적힘 |
| 5번째 이미지 (이름 [확인 필요]) | 배치 미정 | 요청서에 용도 없음 |

- 이미지 자리의 크기·비율은 디자이너가 정한다. 390px 폭에서 가로로 넘치지 않아야 한다.
- 대체 설명(alt) 문구는 파일명 의미에서 쓴 제안이며 실제 사진 내용은 확인 전이다.

## 확인 필요 목록
1. [확인 필요] '구독 시작하기' 버튼이 연결될 주소(결제·가입 페이지 등). 요청에 없음.
2. [확인 필요] 상품 카드의 '구독하기'와 '담기' 버튼 처리. 방문자 행동은 '구독 시작하기' 하나라는 목표와 충돌할 수 있다.
3. [확인 필요] 이미지 03, 04의 전체 파일명과 5번째 이미지의 이름·용도. 실제 파일이 없어 지금은 이미지 자리로 둔다.
4. [확인 필요] '9월의 원두'는 오늘(2026-10-15) 기준 지난달이다. 요청 그대로 쓰되 10월 원두로 바꿀지 확인 필요.
5. [확인 필요] 배송 요일, 구독 해지 방법, 첫 달 이후 배송비, 결제 방식, 누적 고객 수, 수상 이력은 요청에 없으므로 페이지에 쓰지 않는다. 필요하면 사용자에게 받는다.
6. [확인 필요] 후기 이름은 요청의 'OO'를 그대로 쓴다.
7. [확인 필요] 대표 상품·고객 후기 섹션 제목은 요청에 없어 제안 문구로 둔다. 쓸지 여부 확인.
8. 할인·이벤트는 새로 만들지 않는다. '첫 달 배송비 무료'는 요청에 있는 문구만 쓴다.
